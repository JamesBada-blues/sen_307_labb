When I tried to delete the "Library and Information Science" department while a student still belonged to it, MySQL returned Error 1451: Cannot delete or update a parent row: a foreign key constraint fails. MySQL refuses because Department table is the parent table and Student.dept_id is a foreign key that points to it. Deleting the department would leave the student pointing at a department that no longer exists, so the database blocks the delete. I fixed it the correct way in two steps: first I used UPDATE to move the student to another department (Software Engineering), so nothing referenced the department any more, and then the DELETE succeeded. The student was moved rather than deleted, and Department was back to 5 rows. Another way to handle this would be to define the foreign key with ON DELETE CASCADE, which automatically deletes the dependent students along with the department , or ON DELETE SET NULL, which keeps the students but clears their dept_id. I could also have deleted the dependent student rows manually before deleting the department.
